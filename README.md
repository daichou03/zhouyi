# 州弈 · 区域制围棋

浏览器试玩版可部署到 GitHub Pages，并会自动使用内置AI。发布步骤见 [GitHub Pages 试玩版](docs/github-pages.md)。

一个可玩的区域制围棋原型：标准围棋落子/提子规则，中国式数子，并按区域实行“赢家通吃”。

默认开局采用 19×19 棋盘、随机区域、棋盘数据叠层和安全州规则。安全州数量在玩家尚未手动修改时，会随棋盘与区域数量自动采用推荐值。

页面加载时仅展示待开局的棋盘预览；选州、AI和落子计时只会在玩家点击“开始新对局”后启动。

开局可以选择固定版图或随机版图。随机版图支持按棋盘大小推荐的“少、标准、多”区域数量、规整/自然/复杂三种边界风格，以及可复现和分享的地图种子。生成器保证每个区域连通，并通过多候选质量评分减少飞地、长触手和夸张锯齿。

固定版图现包含两张地理趣味地图：15×11澳大利亚大陆地图有七个州与领地、共37分，不包含塔斯马尼亚；19×13美国大陆地图把连续州合并为15个区域、共100分，安全州默认每方3个。澳大利亚首都领地作为1分飞地参与计分，但不能被选为安全州；美国首都特区在初版中并入中大西洋。

黑方与白方可以分别设置为玩家或 AI，支持双人同屏、玩家对 AI、AI 对玩家和 AI 自战。

玩家对 AI 时，AI 不会主动要求换边；AI 每次成功落子后会自动播放“对方上一手”收缩圆圈，方便玩家在数据叠层之下定位新棋。

AI可选择性连接本机KataGo：KataGo提供普通围棋候选与策略先验，内置搜索器继续负责区域赢家通吃决策；没有配置KataGo时会自动使用内置AI。

可选的“安全州开局”会先进入换边竞价：首次选州前，当前白方可以要求换成黑方，每次换边都会令白方额外增加0.5分；有人开始选州后竞价结束。随后白方先选，双方轮流选择互不重复的安全州。选满后进行 N 轮受限布子：每回合可任选一个尚未布子的己方安全州落子，每个安全州恰好获得一枚开局棋，随后进入自由对弈。玩家和 AI 均支持完整流程。

右侧区域战况提供可随时切换的棋盘数据叠层，在每个州的中心显示州编号与名称、该州总分和当前黑白占领数。

进入自由对弈后，区域底色和数据标签会同步反映当前优势方：黑方领先为黑色、白方领先为白色、胶着为灰色；选州与安全州布子阶段则优先显示安全州归属。

对局中的区域优势采用保守的实时影响估算：棋子本身始终计入，附近空点只在双方都已落子且一方具有明确距离优势时计入；不确定空点保持中立。阴影透明度随领先幅度变化，控制权改变使用约 220ms 的平滑过渡。终局确认仍使用严格的中国式面积计分。自由对弈时，安全州身份由数据标签角落的黑白盾牌保留显示。

```bash
npm start
```

浏览器访问 `http://localhost:5173`。运行规则引擎测试：

```bash
npm test
```

运行可复现的成对 AI 自战试跑：

```bash
npm run simulate -- --pairs 30 --size 9 --regions 5 --safe 1 --seed pilot --out reports/pilot
```

命令会在同一地图上交换两个智能体的黑白方，并输出包含地图指标、逐局棋谱和汇总统计的 JSON 与 Markdown 报告。当前 AI 与自动停手只适合验证实验管线和发现异常，不代表正式平衡结论。

运行随机版图结构批量分析：

```bash
npm run analyze:maps -- --samples 12 --seed EXP-002-main --out reports/EXP-002-map-study
```

该命令覆盖三种棋盘尺寸、三种边界风格与三档区域密度，并输出结构摘要、逐图指标和人工评审候选。自动风险分仅用于抽样，最终可读性仍由盲评确认。

运行AI 2.0与旧AI的9路换色基准：

```bash
npm run benchmark:ai -- 10 ai-v2-check
```

## 架构

- `src/engine.js`：棋盘拓扑、围棋规则、区域划分与计分。规则只依赖图的邻接关系。
- `src/ai.js`：区域价值、候选着排序与PUCT树搜索。
- `src/tactics.js`：弱棋块检测、真眼判断和有限深度局部攻防读取。
- `src/katago.js`：浏览器端KataGo请求、坐标转换、合法着过滤与失败降级。
- `scripts/katago-bridge.mjs`：持久KataGo Analysis Engine进程及请求匹配。
- `src/match.js`：对局阶段状态机与阶段合法操作。
- `src/record.js`：棋谱序列化、校验与事件回放。
- `src/simulation.js`：确定性自战、成对换色、地图指标与批量统计。
- `src/app.js`：Canvas 棋盘与界面交互。

连续两次停一手会进入终局确认。此时点击棋盘上的任意棋块可将整块标记为死子，区域比分会按照移除死子后的局面实时重算；确认后锁定结果，也可恢复对局继续落子。

下一阶段可将 `GridTopology` 替换为任意图拓扑，或在 `GoGame` 构造时传入开局棋子，不必修改计分与界面状态逻辑。
