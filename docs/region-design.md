# 区域系统设计笔记

本文记录区域制围棋的区域设计方向，以及随机区域生成的建议方案。

## 一、区域设计方向

### 1. 地理式固定区域

区域可以采用不规则州、狭长州、飞地、环形区域、都市圈和边疆州等形态。默认规则下，区域边界只影响计分，不阻断棋子的气与连接，以降低理解成本。

### 2. 人口与地标

交叉点可拥有不同人口权重，例如普通点 1、城市点 3、首府点 5、荒地 0。区域胜负由所控制的人口而非单纯面积决定，使小面积高价值地点成为战略目标。

### 3. 摇摆州与安全州

区域可以通过开局棋子、地形和分值形成安全州、摇摆州、铁票州与战场州。玩家需要在进攻对方优势区域和争夺高价值摇摆区域之间选择。

### 4. 不同分配制度

区域可采用赢家通吃、比例分配、门槛制、超级多数、席位制或少数奖励。计分制度应作为区域属性，而不是写死为全局规则。

### 5. 动态边界

后期模式可以尝试边界移动、区域分裂、区域合并和控制关键点后扩张。动态边界的认知负担较高，不建议作为默认玩法。

### 6. 区域关系

相邻区域可以产生连续控制奖励、首都依赖、港口网络、包围惩罚或联邦多数奖励，让玩家考虑跨区域战略，而不是只计算孤立区域。

### 7. 特殊胜负指标

区域可分别比较中国式面积、领地、棋子数量、最大连通块、提子数或首府控制。不同指标适合用作特殊地图或高级模式。

### 8. 玩家参与划区

可以设计轮流放置边界、由一方划区另一方分值、秘密指定双倍州或有限次数重新划区等开局阶段。这一方向与选举制度中的选区策略高度契合。

### 9. 区域数据结构

```js
{
  id,
  name,
  nodes,
  electoralPoints,
  scoringMethod,
  allocationRule,
  landmarks,
  neighbors,
  modifiers
}
```

区域形状、胜负指标和分数分配应当相互独立，方便组合不同玩法。

## 二、随机区域生成目标

随机地图应满足以下硬约束：

1. 每个区域必须是四方向连通的。
2. 每个棋盘点只能属于一个区域。
3. 区域面积不能过小或过大。
4. 不允许孤立点、飞地和宽度为一格的长触手。

同时优化以下软目标：

- 区域具有适度的不规则性，不退化为矩形切割。
- 边界平滑，减少犬牙交错。
- 区域尽量紧凑，但不要求完全圆形。
- 相邻区域数量适中，地图关系容易阅读。
- 高价值区域不会系统性偏向棋盘某一侧。

## 三、推荐算法：受约束的区域生长

### 阶段 A：生成种子

根据棋盘大小选择区域数量。例如 9×9 使用 4–6 区，13×13 使用 6–9 区，19×19 使用 9–14 区。

使用最远点采样生成种子：第一个种子随机放置，之后每次选择距离现有种子集合最远的候选点，并加入少量随机扰动。种子之间设置最小距离，也避免全部落在边缘。

这种方法比完全随机选点更容易得到面积均衡的区域。

### 阶段 B：多源随机生长

每个种子最初构成一个区域。重复选择一个尚未达到目标面积的区域，从其边界候选点中扩张一格。

候选点使用以下代价函数：

```text
cost =
  1.8 × 新增长边界数
  + 2.5 × 凹陷惩罚
  + 4.0 × 窄通道惩罚
  + 1.2 × 到种子的归一化距离
  + 2.0 × 超出目标面积的比例
  + 随机扰动
```

代价越低越优先。随机扰动控制地图变化程度，建议只占总代价的 10%–20%。

关键规则：

- 候选点必须与该区域四方向相邻，因此连通性天然成立。
- 优先选择与该区域有两个或更多相邻边的点，可填平凹口。
- 强烈惩罚只通过单格颈部连接的新增长条。
- 区域达到目标面积后降低其扩张概率，而不是立即完全停止，避免留下无法分配的空洞。

### 阶段 C：填充分配空洞

若多个区域围住尚未分配的点，按以下顺序决定归属：

1. 能消除凹口的区域。
2. 当前面积低于目标的区域。
3. 与该点共享边最多的区域。
4. 仍然相同时随机选择。

### 阶段 D：边界平滑

进行 2–4 轮局部平滑。检查每个边界点，如果它只与本区一个点相邻，却与另一区域两个或三个点相邻，则尝试改变归属。

每次改变前必须验证：

- 原区域移除该点后仍然连通。
- 新区域加入该点后仍然连通。
- 两个区域都不违反最小面积。
- 修改后的总边界长度确实缩短，或消除了单格凹口。

不要持续平滑到稳定状态，否则随机区域会逐渐退化为过于规则的形状。

### 阶段 E：质量评分与重试

为整张地图计算质量分。若低于阈值，则更换随机种子重新生成。生成一张小棋盘地图成本很低，因此“生成多个候选并择优”比设计过度复杂的单次算法更可靠。

建议一次生成 20–50 张候选图，从中选择总评分最高的一张。

## 四、地图质量指标

### 紧凑度

可使用：

```text
compactness = area / boundingBoxArea
```

也可以比较区域周长与同面积正方形的理想周长。紧凑度不应要求满分，但低于约 0.45 的区域通常过于狭长或凹陷。

### 边界曲折度

统计边界每次改变方向的次数。短距离内连续左右转向应受到额外惩罚，这比只计算总周长更能识别犬牙交错。

### 凹陷深度

检查区域包围盒中的非本区点，或从区域外部计算进入凹口的最短路径。深度超过 2–3 格的窄凹湾应受到明显惩罚。

### 最小局部宽度

识别连接区域两大片主体的单格或双格通道。单格长通道应禁止；短的单格颈部可以允许极少量，以保留自然感。

### 面积偏差

为每个区域预先生成目标面积，允许约 ±20% 的变化。若区域分值与面积无关，可以容许更大的面积差异，但不应产生只有数个点的区域。

### 邻接复杂度

区域通常以相邻 2–4 个其他区域为宜。一个区域同时与几乎所有区域接壤，往往意味着它过于蛇形。

## 五、控制随机风格的参数

可以向玩家提供少量容易理解的预设，而不是暴露全部算法参数：

- **规整**：随机扰动低，边界平滑 4 轮，紧凑度要求高。
- **自然**：中等扰动，边界平滑 2 轮，推荐作为默认值。
- **破碎**：扰动较高，允许少量狭长区域，但仍禁止飞地与长触手。

另外提供区域数量和面积均衡度两个选项即可。玩家不需要理解内部的周长权重或凹陷深度。

## 六、推荐的首版范围

首版随机分割只实现：

1. 四方向连通。
2. 受约束区域生长。
3. 局部边界平滑。
4. 紧凑度、最窄通道和面积范围检查。
5. 多候选择优。
6. 使用颜色叠加与加粗边界清楚显示区域。

暂时不加入飞地、动态边界和区域规则差异。等随机地图的可读性与公平性验证完成后，再引入人口、地标和特殊计分。

## 七、区域数量与玩法影响

区域数量不应只按绝对值设定，更重要的是平均每区包含多少交叉点：

```text
平均区域面积 = 棋盘节点数 / 区域数
```

### 建议范围

| 棋盘 | 入门范围 | 标准范围 | 高复杂度范围 |
|---|---:|---:|---:|
| 9×9 | 3–4 区 | 5–6 区 | 7–9 区 |
| 13×13 | 4–6 区 | 7–10 区 | 11–14 区 |
| 19×19 | 6–9 区 | 10–14 区 | 15–20 区 |

默认值建议分别使用 5、8、12 区。随机生成器可以允许更宽的范围，但当平均区域面积低于约 15 个点时，区域结果会越来越容易被单次战斗或一两颗棋子改变。

### 少量区域

区域数为 2–4 时，每个区域近似一场大型战役。玩家容易阅读局势，围棋本身的全局连接与厚势价值保留得较好。但区域翻转会造成巨大比分摆动，也容易出现一方较早锁定大区后胜负失去悬念。

适合教学、短规则说明和首次试玩。

### 中等数量

区域数为 5–12 左右时，玩家可以在安全区、摇摆区和放弃区之间分配资源。局部失利不会直接决定全局，也更容易产生“赢得总面积却输掉选举分”的核心体验。

这是最适合默认玩法的范围。区域之间应当存在一定分值差异，但最高分区不宜超过总分的约 20%–25%。

### 大量区域

区域数超过 12–15 后，玩法会更接近多个小型选区。精确计算、抢先手和局部侵消变得更重要；大模样和跨区厚势的直接计分价值降低。玩家需要频繁扫描各区，认知负担显著增加。

过小的区域还会产生几个问题：

- 一两枚棋子即可取得区域领先。
- 区域翻转过于频繁，实时比分噪声较大。
- 死活尚未确定时，领先提示可能具有误导性。
- 边界和颜色覆盖棋盘信息，降低可读性。
- 赢家通吃的随机性和先手优势被放大。

大量区域更适合作为高级、快节奏或席位制模式。

### 奇数与偶数

若各区域分值相同，使用奇数个区域更容易避免最终平局；但只要区域分值不同或总分设计为奇数，区域数量本身不必为奇数。

### 区域数量与分值

区域越少，分值应越接近，避免单一区域支配整盘。区域越多，则可以增加分值差异，形成少数关键摇摆州。

建议约束：

- 最高分区不超过总分的 25%。
- 最低分区至少具有平均分值的 40%–50%。
- 任意两个最大区域的合计分值不应直接达到获胜门槛。
- 面积与分值保持中度相关，而不是完全正比。

### 推荐默认配置

- 9×9：5 个区域，总分 51 或 101。
- 13×13：8 个区域，总分 101。
- 19×19：12 个区域，总分 101 或 201。

界面可以提供“少、标准、多”三个选项，并在旁边显示实际区域数。随机生成时，区域数还应参与质量阈值计算：区域越多，允许的最小面积与边界复杂度必须相应收紧。

## 八、安全州开局

安全州规则分为三个阶段：

1. 白方先选择一个尚未归属的州，之后双方轮流选择，直到各有 N 个安全州。
2. 从黑方开始进行 N 轮受限布子。每轮双方可以任选一个尚未布子的己方安全州下一手；使用后该州不能再次获得受限开局棋。
3. 完成全部 2N 手后解除区域限制，进入正常对弈。

白方先选州用于补偿黑方先落子的优势。安全州仍参与正常的赢家通吃计分，并不提供额外分数或永久保护；“安全”仅代表开局选择与初始落子机会。

推荐值为区域总数的约 20%，四舍五入后限制在 1–4 之间：5 区取 N=1，8 区取 N=2，12 区取 N=2，16 区取 N=3。双方安全州合计最好占全部区域的 35%–50%，为中立摇摆州保留足够空间。

## 九、固定趣味地图：澳大利亚

当前版采用15×11长方形棋盘和7个区域，总分37：西澳6、北领地4、南澳5、昆士兰7、新南威尔士8、维多利亚6、首都领地1。为减轻东南角的区域与分值密度，该版本不包含塔斯马尼亚，原右下角空间并入维多利亚。

区划保留现实地图的主要相对位置和直线边界特征，但不模拟海岸与海洋。设计目标是让玩家一眼识别澳大利亚内部区划，同时保持全部交叉点可落子、普通区域没有一格宽长触手、边界不会干扰围棋棋形。

该地图默认安全州 N=1。首都领地由4个交叉点构成，是新南威尔士内部的飞地；它正常计分，但禁止被选为安全州。需要重点试玩验证：西澳低分大面积是否缺乏吸引力、东部高分密集区是否过强、ACT是否形成有趣的小目标而不是免费分。
