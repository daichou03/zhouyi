# 《州弈》平衡实验与决策记录

> 文档状态：实验框架与初始基线  
> 更新日期：2026-09-23  
> 本文用于记录数据、人工判断与规则决策。任何阈值在完成校准前都只是建议起点。

## 1. 为什么需要独立记录

《州弈》的地图、先手补偿、安全州和 AI 相互影响。只记录“把 N 改成 2”会丢失作出决定的原因，也无法判断后来出现的变化来自规则、地图还是 AI。

每项正式调整都应保留：

- 原始假设；
- 实验版本和参数；
- 样本与随机种子；
- 定量结果；
- 人工地图或棋谱评审；
- 已知混杂因素；
- 决策及复验条件。

## 2. 证据等级

| 等级 | 含义 | 可以支持的结论 |
|---|---|---|
| E0 | 设计直觉或单盘观察 | 提出假设 |
| E1 | 可复现程序测试 | 证明流程和计算正确 |
| E2 | 小规模 AI 试跑 | 发现异常、估计方向 |
| E3 | 成对大样本自战 | 得到当前 AI 下的统计结论 |
| E4 | 多组真人试玩 | 判断理解、乐趣和主观公平性 |
| E5 | 增强 AI 与真人结果一致 | 暂定正式默认值 |

当前大多数平衡判断处于 E0；规则流程与棋谱复现处于 E1。现有 AI 较弱，因此即使积累大量自战，也不能自动升级为最终平衡结论。

## 3. 实验状态

- **待验证**：已有假设，尚无实验；
- **试跑**：用于检查指标和工具；
- **暂定**：证据支持当前选择，但仍需更强 AI 或真人复验；
- **采用**：作为当前正式默认值；
- **拒绝**：不再继续，除非出现新证据；
- **搁置**：有价值，但当前成本或依赖条件不满足。

## 6. 核心指标

### 6.1 对局公平性

- 黑方胜率、白方胜率和平局率；
- 黑白最终区域分差；
- 同一地图交换颜色后的结果变化；
- 选州先后顺序与最终胜率的关联；
- 不同棋盘和区域数量下的结果差异。

### 6.2 地图公平性

- 区域面积与分值相关性；
- 高分州的中心距离、边角分布和聚集程度；
- 最大州与最小州的面积、分值比；
- 首选安全州与次选州的价值差；
- 同一地图交换颜色后的胜率差；
- 某些地图种子是否产生异常稳定的单方优势。

### 6.3 对局质量

- 对局长度；
- 每盘发生控制权变化的区域数；
- 每个区域的翻转次数；
- 胜负失去悬念的估计手数；
- 最终由少量区域决定、还是存在多条获胜路径；
- 总控制点领先者与区域分胜者不一致的比例。

### 6.4 AI质量

- 新旧 AI 直接对战胜率；
- 固定战术题正确率；
- 明显一手失误率；
- 每手思考时间的中位数与高分位数；
- 不同难度之间是否存在稳定棋力差。

## 7. 建议起始阈值

以下数字只用于发现异常，不自动决定规则：

| 指标 | 试跑警戒线 | 说明 |
|---|---:|---|
| 成对自战黑方胜率 | 低于 45% 或高于 55% | 弱 AI 下只表示需要调查 |
| 单地图颜色互换结果差 | 超过总分 20% | 检查形状、分值或选州策略 |
| 单一区域分值 | 超过总分 25% | 可能支配整盘 |
| 最低区域分值 | 低于平均值 40% | 可能缺乏战略意义 |
| 安全州合计占全部区域 | 低于 30% 或高于 55% | 可能过弱或挤压摇摆州 |
| 平局率 | 超过 10% | 判断是否需要奇数总分或平州规则 |

这些阈值应在第一批数据和地图人工评审后调整。

## 8. 成对自战原则

为了减少颜色和地图混杂，每个基本样本至少包含两局：

1. 使用相同地图与规则，AI A 执黑、AI B 执白；
2. 保持地图不变，交换颜色再下一局。

如果 AI 含随机行为，应：

- 保存每局 AI 随机种子；
- 使用多组种子重复同一配对；
- 报告分布与置信区间，而不是只报告平均值；
- 保留异常局棋谱，确认不是程序错误或重复循环。

地图生成种子、AI种子和实验编号必须相互独立。

## 9. 人工地图评审

结构评分不能代替视觉和玩法判断。每轮地图算法调整应选择一组盲评样本：

- 自动评分最高的地图；
- 接近接受阈值的地图；
- 自动拒绝的地图；
- 数据优秀但视觉可疑的地图；
- 数据一般但可能有趣的地图。

评审者分别评价：

- 边界是否容易辨认；
- 区域是否像自然整体；
- 是否有难以追踪的凹陷或触手；
- 高分州位置是否有战略趣味；
- 是否愿意实际在这张地图上完成一盘。

记录评分前不显示自动质量分，避免锚定。

## 14. EXP-001：批量自战管线可复现性

- 状态：试跑完成，统计管线可用
- 日期：2026-09-23
- 游戏基线：B000
- 关联假设：H01–H07 的测量基础
- 报告：[EXP-001-final-pilot.md](../reports/EXP-001-final-pilot.md)
- 完整数据：[EXP-001-final-pilot.json](../reports/EXP-001-final-pilot.json)

### 问题

能否在无界面环境中复现完整的安全州、落子、停手、终局与棋谱流程，并在同一地图上交换两个智能体的颜色进行成对比较？

### 实现结果

- 地图生成、黑方 AI 和白方 AI 分别使用独立种子。
- 相同配置与种子能够逐事件复现相同棋谱。
- 每张地图进行两局，智能体 A/B 交换黑白。
- 报告保存逐局结果、完整棋谱、区域翻转、提子、安全州选择和地图结构指标。
- 输出机器可读 JSON 与人类可读 Markdown。
- 自动测试覆盖单局复现与成对颜色交换。

### 第一次试跑与修正

最初 10 张地图、20 局全部达到 122 手上限。原因不是规则引擎无法结束，而是当前启发式 AI 没有主动停一手判断。

因此加入透明的自战专用停止条件：至少完成 45 手后，如果各州领先方连续 9 手没有改变，则让双方连续停一手。该条件不进入玩家对局规则，也不声称等同于成熟围棋 AI 的终局判断。

### 最终小样本

配置为 9×9、随机自然地图、5州、每方1个安全州；使用30张地图，每张交换颜色，共60局。

| 指标 | 结果 |
|---|---:|
| 黑胜 / 白胜 / 平局 | 39 / 19 / 2 |
| 决胜局黑胜率 | 67.2% |
| 95% Wilson 区间 | 54.4%–77.9% |
| 智能体 A / B 胜局 | 26 / 32 |
| 平均分差 | 29.383 |
| 平均手数 | 51.583 |
| 平均区域翻转 | 7.583 |
| 达到手数上限 | 0 / 60 |
| 稳定领先后停手 | 60 / 60 |
| 黑方 / 白方横扫配对 | 11 / 2 |
| 智能体 A / B 横扫配对 | 6 / 9 |
| 平均区域面积 CV | 0.121 |
| 平均区域分值 CV | 0.095 |
| 平均紧凑度 | 0.759 |

### 阶段结论

1. 实验管线和棋谱复现可以进入下一阶段。
2. 智能体 A/B 总胜局接近，结果没有明显被某一固定随机流完全支配。
3. 黑方优势信号明显，但不能据此修改正式规则。当前 AI、9路棋盘和自战停止策略都可能放大先手优势。
4. 平均分差较大，后续需要区分是赢家通吃本身、AI棋力还是地图分值造成。
5. 地图面积和分值总体较均衡，但中心—分值相关性在单张地图上从 -0.777 到 0.975 波动很大；需要人工地图样本评审。

### 代表棋谱

- `P2-A`：黑 50.5、白 49.5，最接近的决胜局。
- `P21-A`：黑 51.5、白 48.5，共14次区域翻转。
- `P2-B`：19次区域翻转，适合检查翻州统计是否符合视觉感受。
- `P7-A` 与 `P9-B`：最终 50:50 平局。

这些棋谱包含在完整 JSON 报告的 `games[].record` 字段中，可复制为独立棋谱导入现有回放界面。

### 限制

- 当前 AI 没有搜索、可靠死活判断或正式收官策略。
- 自动终局没有人工死子标记。
- “领先方连续稳定”只适用于试跑，不等同于双方认可终局。
- 样本只覆盖9路、5州、N=1，不能外推到默认19路。
- 当前样本不足以分别估计地图、颜色、选州和随机性的交互作用。

### 决策

- 接受自战与报告架构，继续 EXP-002 地图结构分析。
- 将45手与连续9手稳定视为试跑参数，而非设计规则。
- 暂不调整贴目、安全州顺序或默认 N。
- 增强 AI 后必须复验黑方优势信号。

### 复验条件

- AI评估或搜索发生实质变化；
- 自动停手算法改变；
- 先手补偿、安全州规则或分值算法改变；
- 扩展到13路或19路。

## 15. EXP-002：随机版图结构与可读性

**状态：** 自动分析完成，等待人工盲评  
**样本：** 9/13/19路 × 规整/自然/复杂 × 少/标准/多 × 每格12张，共324张地图  
**种子：** `EXP-002-main`

### 自动分析结果

| 棋盘 | 样本 | 平均最差区域紧凑度 | 平均面积 CV | 平均分值重心偏移 |
|---|---:|---:|---:|---:|
| 9×9 | 108 | 0.645 | 0.137 | 0.029 |
| 13×13 | 108 | 0.578 | 0.141 | 0.025 |
| 19×19 | 108 | 0.525 | 0.145 | 0.022 |

面积与分值在不同尺寸间总体稳定，但棋盘越大，单个最差区域的紧凑度越容易下降。高区域密度尤其容易出现一块明显难读的区域；代表样本 M09 即使采用“规整”风格，最差紧凑度也只有 0.275。这说明当前候选评分重视总体质量，但对单个异常区域缺少足够强的下限约束。

### 人工检查点

从样本中抽取12张代表地图，覆盖低风险、边缘、形状风险与分值重心偏移。评审时先隐藏自动指标，只按第一眼的边界可读性、区域辨识和视觉负担标记“接受 / 边缘 / 拒绝”，再揭示指标比较。

在人工评审完成前，不根据自动风险分修改生成参数。完整摘要见 [`EXP-002-map-study.md`](../reports/EXP-002-map-study.md)，逐图数据见 [`EXP-002-map-study.json`](../reports/EXP-002-map-study.json)。

### 待决定

- 是否为最差单区紧凑度设置硬阈值；
- “多区域”是否应按尺寸分别降低默认复杂度；
- 自动风险分中，最差单区指标是否应高于全图平均指标；
- 分值重心偏移是否确实会被玩家感知为不公平。

## 16. AI 2.0：区域感知搜索初版

**状态：** 可试玩，等待扩大复验  
**实现：** 战术候选着、平滑区域获胜概率评价、PUCT树搜索、后期停手机会  
**基准：** 9×9、5区、10张相同地图换色，共20局

加入弱棋块候选保护、有限深度局部攻防读取和真眼保护后，AI 2.0 对旧单手启发式 AI 取得15胜4负1平，其中执黑8胜、执白7胜。该样本显示搜索版本具有初步提升，但不能据此判断正式平衡。19路空棋盘单手本机耗时约为快速0.24秒、均衡0.60秒、深入1.45秒。

自动战术题现覆盖立即提子、逃出打吃、两口气角部网、真眼保护和紧气着优先。下一步应继续加入征子、倒扑、接不归、两眼活棋与停一手题。搜索逻辑稳定后再移入 Web Worker，避免较深搜索阻塞界面。
